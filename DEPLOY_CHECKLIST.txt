1. ZIP'i ZIP/file upload destekleyen hosting paneline yukle ve arsivi proje kokune cikar.
2. Python 3.11 veya 3.12 sec.
3. Kurulum: pip install -r requirements.txt
4. Baslatma: python -m app.main
5. Environment Variables: DISCORD_TOKEN, OPENROUTER_API_KEY, OPENROUTER_MODEL
6. DATABASE_PATH degerini kalici depolama alanina ayarla.
7. Botu baslat ve loglarda 'Giris yapildi' mesajini kontrol et.
